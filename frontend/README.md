# Ratatosk Client (Frontend)

The official multiplatform Flutter client and administrative dashboard for the Ratatosk AI Orchestrator.

## Features
- **Cross-Platform**: Desktop (Linux, macOS, Windows) and Mobile (Android, iOS).
- **Dynamic Module UI**: Automatically adapts widgets and views based on capabilities reported by the Ratatosk backend.
- **Role-Aware**: Admin control panel vs. simplified, distraction-free companion client.
- **Internationalization**: Full multi-language support (English, French).
- **Material 3 Theming**: Dark and Light themes with custom Nordic color palette.
